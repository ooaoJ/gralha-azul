# Carrocerias Gralha Azul — página inicial

Projeto estático em HTML, CSS e JavaScript puro.

## Como executar
1. Extraia a pasta do ZIP.
2. Confirme que sua imagem está em `assets/images/banner.png`.
3. Abra `index.html` no navegador (ou use a extensão Live Server do VS Code).

## Estrutura
- `index.html` — estrutura e conteúdo da página.
- `assets/css/style.css` — identidade visual, layout e responsividade.
- `assets/js/main.js` — menu mobile, ano automático e navegação ativa.
- `assets/images/banner.png` — imagem principal do banner (adicione a sua imagem aqui).

## Personalizações importantes
- Troque o número fictício do WhatsApp em `index.html` (`https://wa.me/5518999999999`).
- Atualize e-mail, telefone, endereço e textos institucionais.
- As fotos das seções Sobre e Produtos são imagens externas ilustrativas. Substitua os `src` por arquivos locais quando escolher as fotos definitivas.
- As imagens externas exigem conexão com a internet.
